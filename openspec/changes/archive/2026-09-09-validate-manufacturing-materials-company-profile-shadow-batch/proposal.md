## Why

The four-report authority plus BaoSteel and Zhongnan Steel prove that the new company-profile semantic contract can produce source-bound research data, but the path still depends on manually frozen samples/Evidence and sample-specific validation manifests. High-quality production requires one bounded shadow batch that proves automatic Evidence planning, generic manifest admission, controlled model execution, review workload, and empirical precision on genuinely unseen manufacturing/materials reports before any legacy reset or production write is authorized.

## What Changes

- Select and freeze exactly 20 previously unseen, locally valid manufacturing/materials annual reports across SSE, SZSE, and BSE, with explicit diversity and exclusion checks.
- Reuse the existing annual-report asset, PDF outline/page artifacts, chapter selector, Stage 5 semantic service, gateway, projection, and failure taxonomy to generate six-core-chapter Evidence plans without per-company hand-authored page maps.
- Replace Stage 5 sample-name hard-coding only for the new shadow-batch application path with manifest-bound identity and hash validation; historical four-report and OOS operators remain closed and unchanged.
- Execute report-local, scope-bounded semantic requests under one primary model policy, bounded typed retries, immutable per-report bundles, and no cross-model or cross-run record splicing.
- Produce batch metrics and a source-text review package covering completion, Evidence traceability, critical semantic errors, human-review workload, latency, token use, and sampled precision.
- Keep every result `accepted_for_review` / research-only and retain `production_authorization=not_authorized`; do not run Stage 6 reset, approved-table writes, scheduler/backfill, commodity exposure, value-chain publication, or DCF.

## Capabilities

### New Capabilities

- `company-profile-manufacturing-materials-shadow-batch`: Defines the frozen unseen cohort, automatic Evidence-plan requirements, bounded batch execution, review sampling, readiness metrics, and research-only closure.

### Modified Capabilities

- `company-profile-bounded-semantic-workflow`: Allows the existing semantic workflow to admit a report through a versioned hash-bound shadow manifest instead of a hard-coded sample constant, while preserving report-local scope bounds and historical Stage 5 closed sets.

## Impact

- Affects `research/company_profile/` manifest/preparation and bundle admission, the existing business-profile PDF outline/section-selection adapters, a thin shadow-batch operator, focused tests, and versioned shadow artifacts.
- Reuses existing local annual-report assets and LLM gateway profiles; it introduces no new downloader, PDF engine, LLM client, semantic object family, production database, scheduler path, or approval framework.
- The shadow cohort and outputs remain isolated. Production configuration, legacy approved facts, historical four-report/BaoSteel/Zhongnan bundles, Gold expectations, Stage 6, and all downstream production consumers remain unchanged.
