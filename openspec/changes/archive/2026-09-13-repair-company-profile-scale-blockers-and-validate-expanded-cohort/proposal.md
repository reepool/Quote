## Why

The September 13 fresh-cohort run preserved 362 source-traceable facts but left every
report `hold` or `failed` because five recurring execution, reconciliation, coverage, and
Evidence-selection defects prevented otherwise usable chapters from closing. These are
shared path defects with observed cross-company impact, so they should be fixed once and
validated on a larger unseen cohort instead of continuing company-specific reruns.

## What Changes

- Reserve useful execution time for remaining members of a bounded logical LLM route so
  one slow source cannot consume nearly the entire failover deadline.
- Reconcile closed annual period aliases across segment partitions while preserving
  distinct years, interim periods, instant dates, and physical row identities.
- Close required coverage from accepted source-supported facts or owner-bound legal-empty
  results without synthesizing facts or hiding verifier failures.
- Accept explicitly labelled `分部间抵销` / consolidation-adjustment rows through the
  existing narrow guard while keeping ordinary subject and inference restrictions.
- Extend the existing owner-aware Evidence selector only for the operating-capacity,
  operating-quantity, and business-regime source shapes missed in the frozen cohort.
- Freeze eight previously unseen local-valid manufacturing/materials annual reports and
  complete six-chapter Evidence plans, then execute exactly one immutable four-model
  validation batch and source-review its observed result.
- Keep all outputs research-only with `production_authorization=not_authorized`; no Stage
  6, approved write, scheduler/backfill, CommodityExposure, ValueChainRole, or DCF path is
  opened.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `common-llm-gateway`: bounded failover must reserve a meaningful attempt window for
  remaining eligible members without extending the logical request deadline.
- `company-profile-bounded-semantic-workflow`: annual partition reconciliation, accepted
  coverage closure, and explicit consolidation-adjustment verification are corrected.
- `company-profile-manufacturing-materials-shadow-batch`: owner-aware Evidence selection
  covers the observed missing disclosure shapes and one expanded frozen cohort validates
  the repairs.

## Impact

- Affects `utils/llm/client.py`, existing company-profile Stage 5 provider/service logic,
  shadow Evidence selection, the existing shadow operator, focused tests, and one new
  immutable validation artifact set.
- Reuses the current logical pool, Stage 5 application service, schemas, projection,
  storage, and review owners; no new retry framework, confidence platform, semantic
  vocabulary, provider ranking system, or production datastore is introduced.
- Historical bundles, Gold expectations, task-start LLM configuration, public APIs,
  schedules, and production data remain unchanged.
