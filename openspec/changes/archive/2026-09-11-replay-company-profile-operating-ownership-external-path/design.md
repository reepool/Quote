## Context

The archived replay `manufacturing-materials-shadow-operating-ownership-gemini-20260911-a`
crossed its authority boundary inside a restricted network namespace. Its first persisted
report contained eight uniform pre-HTTP DNS failures; an external read-only check resolved
and reached `scorpio.reepool.com` immediately. The run therefore could not evaluate any of
the seventeen v6 ownership-affected scopes.

The existing planner, preparer, Stage 5 semantic service, report-local output store,
review/readiness builders, and comparison code remain authoritative. The user has granted
standing authorization for file transfer to `scorpio.reepool.com` and for the necessary
external execution path.

## Goals / Non-Goals

**Goals:**

- Bind the archived failed attempt and every previously frozen semantic input to one new
  transport-recovery replay proof.
- Admit a new immutable batch only when the output is absent and the cohort, PDFs, v6
  Evidence, implementation, Gemini route, budgets, review rule, and readiness gates match.
- Launch the complete provider-bearing process outside the sandbox from its first semantic
  request and quantify the real effect of the ownership correction.
- Produce complete source review, readiness, seventeen-scope recurrence, and immutable
  before/after artifacts for a terminal `ready`, `hold`, or `failed` result.

**Non-Goals:**

- No Evidence, prompt, schema, verifier, subject, Gold, model, timeout, token-budget, or
  cohort change.
- No targeted rerun, candidate splice, historical mutation, generalized external runner,
  production writer, Stage 6, approved table, scheduler/backfill, commodity exposure,
  value-chain publication, or DCF path.

## Decisions

1. **Use a new batch identity without changing semantic inputs.** The consumed sandbox
   batch remains immutable. The external batch is
   `manufacturing-materials-shadow-operating-ownership-external-gemini-20260911-a` and
   reuses the archived v6 plan and preparation byte-for-byte.
2. **Add one narrow recovery mode to the existing operator.** It reuses the ownership
   proof validator and report-local service; no second semantic loop or general execution
   framework is introduced.
3. **Bind the failed attempt as a required input.** Admission verifies the archived failed
   readiness, interrupted-attempt, and persisted-report evidence so the second identity is
   authorized only as transport recovery, not as an unrestricted retry.
4. **Start the provider process externally.** The same read-only profile preflight and the
   full replay command run through the authorized external path. A sandbox success is not
   required because the prior experiment already demonstrated namespace-specific failure.
5. **Keep all provider parameters fixed.** Gemini remains the only model; extract/verify
   output limits remain `20000/18000`, request timeout 300 seconds, call ceiling 600, and
   outer deadline absent. Dynamic token tiers remain a later controlled experiment.
6. **Treat every outcome as terminal.** Once the first semantic request starts, transport,
   schema, semantic, or readiness failure is preserved and the change closes without a
   replacement batch.

## Risks / Trade-offs

- **[External execution still cannot reach Scorpio]** → preserve typed failures and close
  `failed`; do not add retries, change DNS, or tune the semantic contract in this change.
- **[The long batch is interrupted locally]** → preserve report-local outputs and the exact
  interruption receipt; do not reuse the identity or reconstruct a manifest.
- **[Ownership failures improve but readiness remains below threshold]** → report the exact
  source-bound blockers and close `hold`; only observed blockers may motivate a later
  change.
- **[Large valid responses exceed requested token warnings]** → retain diagnostics under
  the fixed budget; warning-only excess is not reclassified as truncation.
- **[Research result is mistaken for production approval]** → keep
  `production_authorization=not_authorized` in every artifact and leave every production
  consumer closed.
