## 冻结的下轮内容尺度

[source-first-contract.json](source-first-contract.json)列12家共133个源核心条件，每家10–13项。来自6.BU运行前独立源参考和本轮必要正式源核，不由当前模型答案反定分母。每条有公司/报告版本、自己的章节路径/物理页、实质预期和现稿对应对象/具体缺项。当前文字对照不是逐核心对象的完整源核，因此条件上的独立完整源判定明确为空，不造新的准确率或召回率。

核心只抓主营及全部主要板块、主要产品/服务、变现、公司收入/主要构成、影响理解的生产/贸易/代理/运营等角色。条件不是逐家公司生产人工答案库；独立参考不送待测模型。供应链位置、资源/客户领域仍为可选，缺项不阻塞；有源近似和边界允许保原文、不强求统一精确值。

六类风险沿原独立实源挑战绑定，每类至少两家公司：正文主次、收入列/空位/单位、主体/期间、购销方向、出租/租入成本与相关范围、金融披露。它们是下一次实际审核任务，不是本轮已经通过的负例；“没出现错误句”不能算挑战通过。
