# 6.CP：通用画像主干与集中章节供源

本轮完成的是通用工程改进和保存材料校准，新增模型调用、探针、可发送绑定均为0，不是新公司成绩或新模型效果。原6.CO真实结果/S1/生产权限不改。

## 信息架构与取舍

继续使用现有八要素和Fact/Metric/Evidence，详见[产品需求的通用分层](../../../../docs/development/company_profile_product_and_industry_semantic_requirements.md#322-通用信息架构与采集取舍2026-11-15接续)：

- 主干回答做什么、主要产品/服务及用途、如何赚钱，不漏主要业务。
- 同一组高价值经营章节优先带回公司收入、主要业务权重、经营角色和客户/渠道；不同科目、主体、期间不混。
- 经营因素/变化按重要性补充，不要求抄全同比、区域行、排名或子公司财务。
- 供应链只需有源的公司位置、投入类别和下游用途，仍是可选加分，不为补满单开阅读。

公司收入与利润、可选比较、未决时点分成可独立使用的事实；不机械增加“一指标一对象”，也不由程序拆句猜答案。抽取提示v16与复核v6已将该取舍送入原公共网关；修订可保住有据核心、删去或保留限定的次要比较，最终核验不能因为没补全可选明细而拒绝正确收窄的核心。
