# 6.ET A扩量裁决：交付分级研究版，暂不扩大正式样本/生产

结论为**限范围研究使用**，本卡研究交付可以收口；正式20/100家或全市场扩量不放行。该裁决与研究版是否有用分开，不是因供应链、可选数字或未取到全部字段而拒绝已有画像。

业务依据：已有15家当前研究内容可解释主营/产品服务/收入，保缺项和限制；本轮真实日常CLI两份首读约36秒可见，随后两份源复核及一次定向精读均完成，六项实际修订得到终核且A对源。已知行业融资口径歧义对象由A局部仅源参考处理，未波及其他公司/事实。最终有单一可供原API显式选用的研究release根、年度JSON与人读版，具体选用及数量见B的release manifest与本轮结果。

不扩大正式验证的依据：

1. 旧S2首次组和唯一确认组已经失败并结束。本轮两家公司是已见日常操作观察，保存15稿也是历史内容及后继，不是另一组20份未见同版首发。
2. 本轮有限对源覆盖主要业务/关键数字和六个实际修订；225条旧判断相同内容/完整引用可复用，272条当前内容绑定独核与其重叠，不能把它们相加或推算正式400补充对象/全组99%。没有新的20家独立源条件，不能制造95%宏召回。
3. 两家并发、三条链631.198秒与332655供应商total足以证明本次日常链运行，不能外推100家通道稳定性、14日全市场时效或人民币成本上限；费用unknown不是0。

后续若开展新正式方案，一次冻结名单/来源/预算/补救/停止，按[验收合同](acceptance-contract.md)及验收计划v2执行20→100→分波全市场，不能逐次补五家/加第41家来改旧分母。本卡不再给剩余补充项续窗、不重抽原15家、不启生产、DCF或交易。
