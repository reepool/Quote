# 6.EY A独立读源与计分方法

固定20名单、6/6/4/4分层及银行/证券/租赁的金融范围、18/20与19/20、95%/99%和400实际补充对象沿已批准整卡。仅评价这次前瞻版本与真实内容，不追改旧失败，不把可选供应链/细项齐全作为公司门禁。

A按每份报告自己的目录/书签/正文标题阅读高价值业务与收入子节，在该公司首次模型前冻结source-reference-batchN.json；元数据页号只为当份来源定位，不成为模型跨公司页白名单。参考不发模型、不调试新公司语义。关键数是独立audit_targets，不是逐数字必填要求。基础三问以有源的实质回答判断，未列齐小产品/子公司服务/尾项只提示缺项，不自动拒稿；若主业/主要产品或赚钱方式仍不可判断则保部分并明确基础不完整。

补充审查沿既有固定种子20261122，不看输出调种子；本文件在读取任何新模型正文/候选之前显式落盘。此时首四家已产生待核稿，A只查看了执行数量/状态，未读取新模型正文或据其选择样本。后续抽样仅由固定身份和哈希排序决定，不选择易对对象。此时点限制如实保留，不称统计随机总体估计。

- A核全部三基础问、主要数字与所有实际采纳修订，记录原页、对象及支持/错误/不确定；模型自核和字段存在不代替A判断。
- 对每家公司实际最终可读对象，以完整reading_work_id+fact_id定位并核实是否重复同一断言；先标出用于三个基础定性问题的最小实质对象集合。主要数字、其他量化指标及实际修订依原合同可属于补充样本，并可与风险/修订检查组重叠，但最终唯一对象准确率只计一次；不能因为做过一次关键数核查就把实际补充对象从采样总体删去。
- 其余实际补充对象按SHA256(`6.EY:20261122:<instrument_id>:<reading_work_id>:<fact_id>`)升序取每股20个；不足20全部审。若全组仍不足400，按同一顺序分层轮转追加尚未审核的实际对象，最多至400，不新增公司/虚构对象或拆一个多指标事实凑数。全部候选仍不足400则如实未满足样本量，不制造通过。
- 来源以匹配报告hash的正式PDF为准，抽取Evidence用于定位而不是自证；A可读原文片段/表头/跨页上下文，保科目/主体/期间/单位。按源明确不确定的近/约/超和有源冲突可限用，不强逼精确统一。已知错数/错主体/无据确定断言只隔离具体对象及依赖结论。
- 核心召回按每家公司冻结三问题分别判断后宏平均，未交付/未启动保20分母；重要补充缺项不作为新的核心分母。准确率按实际独核唯一对象去重计数，核心、补充、修订重叠不重复算；未审不默认正确。首次与后继/独立隔离后使用范围分列。

口径澄清：初稿曾把“核心/关键数/修订已查集合”全部排除出补充总体，会无故把按产品总需求本属补充的量化事实变成额外必填/重复工作。A在尚未分配或计分补充样本时予以纠正，保原seed、400实际唯一对象和原95%/99%不变；此时只读了德赛/大秦两份当前稿，没有用对错结果调seed或选择易审对象。相同断言的逐字重复和旧后继重复仍不充数量；不是把少于400改称满足。

同核心根因连续两家失败、已知不可隔离底线或已不可逆的正式不通过按原卡停止/止损，不为补足审查数量继续无意义付费或扩样。无新100家/生产权限。可交研究内容与正式验收分开，A独核范围/未评项目如实交接。

执行分工：主A已逐股亲读20份目录/高价值原文并冻结前述参考；末端逐对象原文核查中，主A直接核派发序1—10，另由两名A侧独立审核助手按固定派发序11—15、16—20并行读正式PDF、对照真实最终稿，写入各自的a-semantic-audit-group-b/c.json。这些助手不属于B开发自检，不运行模型、不改业务代码/原结果/模型输入或发布；主A复核其范围、hash抽样、错误的原文证据及主要结论后裁决。不得将助手的核查冒称全部由主A逐条亲核，也不得把B机械绑定/模型意见当独立语义。此分工不改变seed、样本、阈值或原始成绩，不按已发现对错挑选分工。
