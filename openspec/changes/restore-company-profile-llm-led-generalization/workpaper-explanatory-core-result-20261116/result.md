# 6.CS：先解释主要业务，再保留有价值的自主发现

已把上一轮四家公司暴露的主次问题落实到实际抽取、初核、修订与最终再核指引。新版prompt v18/review v8；八要素及可选company_features、guide v4、预处理/源绑定v4、原网关/唯一writer均不变。没有新增行业科目字典、特色分类、数量门槛、语义正则或付费阶段。

## 这轮改了什么

- 已读材料有紧凑主要收入构成时，先保留全部主要类别及有据金额/占比，再取次要经营数字；公司总额或最大一项不能代替构成解释。由模型按当份原文判断主次，不要求所有尾项，不计算或猜补缺失值。
- 自主特色仍由LLM决定。优先问“这条信息具体帮助理解公司的什么”，鼓励有源机制/资源/变化；这不是允许清单或新增字段。荣誉、口号及子公司数字只有有解释价值才展开，低解释价值只是写作取舍，不单独触发修订、隔离或补读；其他有据的新颖信息仍可保留。
- 勾选“不适用”保留为披露项目状态，不扩大为经济变化/事件未发生。抽取、初核、修订与final都明确这一范围；计划文字和结构化期间共同核对，避免次年计划变成当期成果。
