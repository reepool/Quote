# 6.FL：公司画像显式任务入口已交付

本轮完成用户授权的研究HTTP入口：提交股票清单或单股补读问题，立即获得任务ID，后台沿原TaskService执行，状态和结果通过API读取。首读先交待核稿，随后显式提交复核；用户可在等待期间读取已有画像，再按需要补读。用法及完整请求示例见[HTTP任务说明](../../../../docs/research/company_profile_http_tasks.md)。没有安装实际执行策略、启动生产服务或新增付费年报处理。

实现只增加领域任务适配、薄路由及生命周期接线；请求账保存计划/状态/安全摘要，事实仍由原writer写入、原reader读取。服务端策略冻结股票/报告/原模型和有限任务数/每任务预算，客户端不能改文件路径或模型端点。相同请求幂等、冲突409、额度用尽429，策略漂移不能刷新额度。同范围HTTP任务串行；关闭先停接收并join实际工作线程，重启中断任务不自动重发。结果是当前保存画像，明确区分本次新增、原有可读稿和审核状态，不以completed冒充语义准确。

A审中发现并修正的阻塞是任务策略影响原查询root：现普通查询保持原路径，错位策略只拒新任务，不切换查询数据集。B另修正后续稿错误归属本任务及关停收尾。未扩成通用调度平台、第二事实库、逐公司规则或语义校准工程。非阻塞旧风格检查未扩大处理。
