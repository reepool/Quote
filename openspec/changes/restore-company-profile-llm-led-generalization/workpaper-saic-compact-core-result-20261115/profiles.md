# 上汽集团：本次真实画像的主要内容

本轮一次全新处理已交35条事实、64个指标（含可选供应链），真实完成抽取→初核→一次修订→再核，仍是研究底稿。以下只摘录本轮实际入稿并对照来源的主要内容，不另生成一份模型答案。**原稿mc-02的“未发生重大变化”不作为结论采用**；原query及模型回执保留不改，其他未逐条核过的事实也不冒称全准。

## 公司做什么、卖什么

汽车集团，以整车业务为主，涵盖零部件、劳务及其他、金融；实际业务还包括安吉物流、Robotaxi商业运营。车型包括基本乘用车、SUV、MPV、交叉型乘用车、客车与载货汽车，新能源整车分乘用车和商用车。稿中保留了与华为合作推出尚界H5、华域开展零部件业务、合资经营与联营合营投资收益等内容。

来源：第三节管理层讨论与分析“一、报告期内公司从事的业务情况”（物理8页）、“核心竞争力分析”（10页）、主营业务分析（10—11页）、行业经营性信息分析（17—19页）。具体零部件产品和合资车型未展开，不为补满名单跨读华域另一份年报。

## 经营方式、供应链和变化

公司具有研发、制造、营销体系；除上汽大众MEB工厂外，其他新能源产品与传统车共线生产、共享产能，实行柔性化生产。成本类别包括原材料、人工工资、折旧、能源；稿中另保留汽车芯片及相关零部件出口贸易业务。尚未收齐具体原材料和下游客户类型，供应链仍为可选加分项。

半固态电池、“银河”全栈智能车方案、VMC已量产，与全固态电池、高阶智驾等持续推进事项分开。上汽红岩司法重整方案获批并启动等变化也已入稿。来源：第三节8页、核心竞争力10页、成本与贸易12—13页、新能源工厂表18页。
