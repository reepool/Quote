# 十二家画像：现在能交付什么，发布还差什么

结论：现在已有[十二家公司有源研究预览](/home/python/Quote/docs/development/company_profile_research_preview.md)，不必继续为单家公司补句才能看到产品。但它仍是**跨窗口、限用、未正式接受的研究材料**，不是12家公司同版验收通过或生产发布。

## 现在可以直接看什么

九家采用6.CT真实query，上汽/海泰采用6.CV接续结果，广州采用6.CX复核稿。十二份都保留实际模型正文来源、报告版本、事实及Evidence身份；广州原抽取合同仍rejected，格式恢复和后续真实复核分开，不能称12份全部新抽取成功。

原稿共371对象/533指标，本页摘录266个唯一公司-fact对象，包含主营、产品/服务、收入来源、主要规模/构成、经营方式、客户渠道、驱动变化以及适用的供应链和自主特色。索引只引用原query/hash/fact ID，不复制十二份事实库。普通摘录仍标待核；依据已有独立审核屏蔽5个坏对象、4个源参考/解释项单列、1个重复表达去重。不是把未展示的内容判成未披露，也不代表其余对象全部准确。

已保留的模型复核状态为7家completed、3家completed_with_open_findings、2家incomplete。这些不是公司可用等级：青山和开创等即使模型流程completed仍有独立审核已发现的坏项；广州即使incomplete已有实际收入构成纠正。状态与可读性、质量及授权分开。

## 三个真正的发布差距

| 差距 | 当前证据 | 对下一步的影响 |
| --- | --- | --- |
| 正式接受与分级交付未完成 | [runtime.py](/home/python/Quote/research/company_profile/runtime.py:885)的workpaper `_verify`明确把三个维度设为未接受、`core_complete=false`；当前所选12份query的可信事实也为空 | 不能靠把bool改true、检查字段非空或模型completed制造正式可用。下一业务切片须沿原owner表达实际已核、待核、限用/隔离的消费边界，并保原稿审计；再按适用条件接正式接受 |
| 正式同版质量证据仍有缺口 | 6.CT是同版新入口，但只有11份画像；本页另外复用后段，不是重新12/12同版首发。原133核心的112支持/8部分/13缺失只属CT原观察，不能与后段最好结果拼成新分数 | 复用未变事实及已有源核，先明确最终版本、适用核心/风险和补救边界；需要真实验证时再另行有界授权，当前不盲重抽12家。不得改分母、回改首次失败或将旧风险未运行算通过 |
| 完整处理资源与价格未达可发布证明 | CT青山123514、同方121005、林海121849超过常规120000账本；开发额度内不等于常规资源达标。费用多为unknown，CV/CX是后段增量，不是整家公司新处理成本 | 不汇总混合全流程/后段后计算平均成本或速度。按验收计划核完整入口、冷热缓存、实际usage/未知预留和价格依据；费用未知不报0或达标，不为达标削主要业务 |

这些缺口不要求补满供应链、次要数值、荣誉或所有行业字段，也不要求把所有复核意见清零。已有资料能够用于研究内容观察，已知错项不能作为确定事实消费。

## 发布标准沿用唯一验收计划

不另造一套“预览通过率”。[验收计划v2](/home/python/Quote/docs/development/company_profile_acceptance_program.md:115)的正式要求继续有效：

- 公司可用要求主营、产品/服务、变现和主要板块实质成立；已审核心召回至少90%、已审对象准确率至少98%，审查范围内无未处理底线错误。供应链粗粒度可选；有源不确定保原文，不强求精确化。
- S1是最终LLM快照下12家核心正反、真实语义及直接回归的有限验收。当前仍0/12，不因本页12份内容可读自动放行。
- S2先20家未见、S3另100家，分层、首发/补救和质量/资源门槛按原计划；当前未授权启动。后继需同版而非拼接最好结果，已有失败保留。
- 研究生产发布、消费者范围、唯一writer切换和全市场运行须明确授权。当前not_authorized，DCF/交易/价格敏感性不在范围内。

本页只说明差距，不追溯修改已冻结合同、旧分数或未知费用例外。曾经较高的开发额度也不是以后可直接消费的余额。

## 下一步只推进一条主路径

**先接通分级研究交付和正式接受边界，不再围着广州、供应链或状态字符串打补丁。** 基于现有12份结果和审核证据，在原read/runtime/writer链上确定哪些内容能普通展示、哪些仅源参考、哪些禁用；程序不得把同field存在、正则匹配或单一review状态当作语义通过，也不直接发布本页人工策展为自动模型成绩。

这个切片先以保存的真实响应零调用验证，有用正文与已知错误隔离须同时成立；无须先新建质量平台、界面、数据库或通用门禁。随后才对最终版本及尚未满足的正式条件发一张有限验收卡，明确能复用什么、必须新验证什么；有新模型范围时另批准，不把下一步默认成十二家再次付费重抽。

正式接受边界、同版质量和完整资源三项没有成立前，继续交研究预览与具体限制，不能宣称生产可用；但它们也不应再成为向用户展示公司画像内容的前置阻塞。
