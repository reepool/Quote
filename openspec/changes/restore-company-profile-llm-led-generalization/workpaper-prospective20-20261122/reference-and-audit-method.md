# A源先行参考及独立评估方法（首发前冻结）

阶段身份：6.EU prospective-two-phase-20，2026-11-22用户新授权。三基础问题为主营/主要业务、主要产品服务/用途、如何取得收入；全部主要板块和影响经营理解的角色必须回答。数字总额、主要分部金额/权重在原文明确时独立核主体/期间/表头/单位；不要求补充字段全满。

## 参考建立

A对固定名单每家先阅读该正式报告的目录，再优先集中于业务介绍/经营讨论/收入构成章节，以原章标题/节/物理页/文档hash记录参考；补充重大变化和决定业务理解的角色。A参考与模型目录选择互相独立，不用模型输出构造参考分母，也不把参考发给模型。章节内完整业务分类而非目录关键词命中形成期待，所有重要业务按实际披露列出；数字可比时才检查主要构成覆盖，不为单位/口径不一强求加总。

每家主要参考断言分为principal_business、products_services、revenue_model，条件可以由不同措辞、多个有源对象联合满足，不要求字面匹配、固定field或人工原句复现。通常10—30个适用条件是工作量参考，不为凑数拆词/指标；同一含多主要板块的条件必须所有主要部分有支持才能完全满足。补充供应链/客户名单/产品细型号不进入强制分母，原文未明确的条件不造正例。部分得到只标部分，不自动算完整满足。

参考一经冻结不得按模型表现删条件、改主要板块或换公司。阶段原代码/模型/提示/源与预算单独冻结；只可在全组首发保留之后按整卡允许的范围/原余额作共性修复及必要后继，首次及后继分别评分。PDF原生缓存可复用，旧语义/答案不加载。

## 内容独审

A核实际输出对应原文，至少覆盖全部基础支持对象、关键数字、所有模型实际采纳修订和疑点。核心满足/部分/缺失由A语义判断，不由同field存在或正则命中产生。本文不建立新的评分引擎或程序语义注册表。

补充抽审先按既有结构分为含指标与纯文本等实际对象类型，再用冻结种子20261122及股票/work ID/fact ID确定顺序；每股至少20个实际唯一补充对象、不足全查，整组至少400。相同内容跨轮不重复算正确对象，核心/补充/疑点先分别列后按身份和内容去重合计，禁止拿指标条数/引用条数充对象数。计入准确率的是实际已核对象，未核不默认正确；source_only/withheld/未采纳候选不充当前正确事实分母，原首发错误仍保原分数。

审查结果区分：支持；有据不确定/显示精度保真（正确但限用，不进入精确运算）；有源参考但当前断言范围或数字不可靠（仅源参考）；已知错误（隔离）；未核。源复核completed不是准确率，失败/必要未读保可读可靠部分和原因，不伪造负例通过或全报告完整。

## 结论与及时止损

固定20公司都保分母，未启动/未交付核心召回计0、准确率不可评估。若核心宏召回的最有利上限已低于95%、首发可用最多不足18、或同根因止损等导致确定阶段失败，仍保在途可靠稿并交失败结论，不为无意义凑400继续全量人工审计；已做独审样本数、实际问题及未评项如实分列，不能据此报99%已通过。若基本条件有望通过，则完成正式核心/补充/风险/分层及资源全部要求再裁决。

新增已知错误仅影响对应对象/依赖结论，原首次结果和回执不改；A的使用决定在后继研究副本与原writer消费，不手填模型遗漏成自动结果。未出现的新100家/全市场不在本轮默认执行范围。必要证据一套后清A/B临时库、重复源包和日志，原源/有效缓存、正式研究稿/首次失败/attempt保护。
