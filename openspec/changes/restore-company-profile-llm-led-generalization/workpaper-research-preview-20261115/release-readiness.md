# 研究预览与正式发布：当前差距

结论：现有12家公司可集中查看研究底稿，但不能据此宣布同版12家验收或生产发布。当前主要矛盾是**最终版本的连续运行与独立内容验收尚未完成**，不是再加画像栏目、供应链明细或单家公司补句。

## 现在交付什么

[研究预览](/home/python/Quote/docs/development/company_profile_research_preview.md)从现有原query摘录业务、产品服务、收入规模、经营方式、经营变化和可选供应链，附原fact_id、章/节/物理页、实际正文模型、来源版本与原件链接；[JSON索引](index.json)使用同一批原事实，文字及指标不改。选用的是已有有内容的版本，不自动取最新失败入口，也不把旧稿冒充最新成功。

前4家公司和浦发选用已保存真实响应的离线安全读回，origin=controlled_fixture；其原正文作者仍是继承的真实模型，不称本轮新生成或新复核通过。其余选用既有真实稿；开创已补最终再核，上汽已知mc-02误述不作预览结论。全部统一为研究待核，原始全稿仅供审查，不作未经评估的可靠发布。

## 发布要求不另造一套门槛

| 项目 | 当前事实 | 下一步 |
| --- | --- | --- |
| 有内容、有来源的研究预览 | 12家均有可读旧稿，原文版本和事实引用可追溯 | 现在即可用于内容观察；缺项/错误/未核范围保持可见 |
| 程序接收和局部纠错 | 当前版本已有原入口、typed坏项隔离、补充不撤正确正文及开创真实final证明 | 复用有效回归，不继续为可选明细扩协议 |
| 同一实现连续完成整组 | 未证明；现有稿跨版本、跨授权窗口，5份为受控读回 | 当前版本冻结后原12家各一次完整新入口，不载旧语义，整组不热修 |
| 独立核心质量 | 原133个源先行核心条件已准备；当前新版本全组质量未评估 | 用原参考逐核心核原文，不由新输出反定分母，不送参考给模型 |
| 补充与风险核验 | 现有有限源核不能代替正式抽审 | 按验收计划§4.2每家至少20个补充唯一对象（不足全查），全部疑点加查，六类风险实际挑战分列 |
| 正式可用与扩样 | S1仍0/12，S2/S3未放行 | 按原计划分阶段裁决，不以研究稿数量、模型completed或单候选通过替代 |
| 费用/时长 | 开发账本和正式900秒/120000/16门槛分开，费用多为unknown | 下轮精确报告；未知不报0元或费用达标，不为开发额度放宽而改正式标准 |
| 生产接入 | not_authorized，旧writer禁用 | 仅在适用阶段验收及明确授权后接唯一owner；不自动启DCF/交易或全市场 |

公司“可用/限用/隔离”、已审核心召回≥90%/对象准确率≥98%、S2/S3更高的阶段门槛及实际分层，继续仅以[验收计划v2](/home/python/Quote/docs/development/company_profile_acceptance_program.md)为准。本轮没有重新计这些分数，不降低阈值，也不要求供应链齐全。

## 下一次验证只做一张完整批次卡

采用当前已验证的选章、章节供源、紧凑核心JSON、源绑定和review.v5，不再边看样本边改。原12家同版各一次完整入口，旧PDF/有效解析可复用，旧导航/答案/初核/修订/人工参考不载入。模型可留次要缺项及原文不确定，但主要业务/产品、收入机制和影响理解的角色不能因字段齐全而算完整。

范围及硬限见主任务卡6.CO，新的明确合并授权前不绑定、不发模型。批准后整批执行、独立核主要内容/补充/风险、报告首次结果、资源和限制，最后一次交付及清理，不逐公司请批或再开微窗口。可隔离的局部错项不清空公司；核心污染不可隔离或同核心根因连续两家失败则停派，在途按原限收尾。

批次若未达到要求，先集中最多几个共性根因按原补救上限裁决，不能自动给12家逐一补句或无限重跑，也不能立刻增加第13家稀释失败。先完成这一步，再决定20家盲测，不提前承诺全市场质量。
