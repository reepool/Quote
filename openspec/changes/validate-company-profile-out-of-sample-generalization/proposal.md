## Why

The manufacturing/materials company-profile workflow is research-usable on the four reports that shaped its Gold and adjudication rules, but that does not yet show that the same six-chapter contract works on an unseen report. A bounded out-of-sample validation is needed before considering broader industry rollout, while preserving the completed four-report authority and all production freezes.

## What Changes

- Select and freeze one official, locally valid manufacturing or materials annual report that did not participate in the existing sample manifest, Gold annotations, targeted runs, or manual adjudication.
- Prepare the new report with the existing six core chapter families and source-native Evidence rules, without using Gold answers or changing the completed four-report bundle.
- Execute one bounded research-only run through the existing semantic workflow and common LLM gateway, with a new run ID and immutable isolated bundle.
- Determine `usable`, `usable_with_caveats`, `hold`, or `failed` using the current research acceptance policy and closed downstream-usage restrictions.
- Record only genuinely new failure classes or unsupported disclosure forms as out-of-sample findings; do not open iterative targeted-run or rule-tuning loops inside this change.
- Keep every result `accepted_for_review` with `production_authorization=not_authorized`; do not start stage six, legacy backfill, approved tables, CommodityExposure, ValueChainRole, DCF, scheduler, API, or Telegram publication.

## Capabilities

### New Capabilities

- `company-profile-out-of-sample-generalization`: Defines independent sample selection, bounded execution, evidence-backed evaluation, novel-failure reporting, and the research-only completion boundary for an unseen company-profile report.

### Modified Capabilities

None. The existing four-report slice, Gold expectations, acceptance policy, and semantic contracts remain unchanged and are consumed as fixed inputs.

## Impact

- Adds one versioned out-of-sample sample/evidence manifest, one isolated validation bundle, and one researcher-readable generalization report.
- Reuses the existing company-profile preparation, semantic service, task-specific provider, projection, acceptance policy, bundle store, and common LLM gateway; any code change is limited to admitting the frozen validation manifest through the same owner without weakening the four-report mode.
- Does not modify the authoritative `stage55-closure-four-20260907-a` bundle, its offline 18/24 Gold evaluation, historical runs, production databases, public interfaces, or production scheduling.
