remains `docs/README.md`.

## Method

- **Title** is the first level-one Markdown heading, or the basename for
  non-Markdown artefacts.
- **Inbound references** were scanned with `rg -l -F <docs path>` across the
  working tree, excluding archived OpenSpec changes and generated bytecode.
  The number is the observed count; named paths are representative references
  that matter to a later deletion decision. A zero is not permission to delete:
  command and active-change checks are still required.
- **Owner** is the current business/documentation owner, rather than a claim
  about individual code ownership. `W1` owns this inventory itself.
- **Disposition** is deliberately a planning result. `retain` means it is
  currently indexed guidance; `consolidate` requires the named target/runbook
  and the W1 deletion record; `defer` means an active overlapping change or
  user worktree material makes cleanup unsafe; `historical candidate` requires
  a replacement and reference scan before deletion.
