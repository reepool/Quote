## 二、需要调整的原稿判断或验收

1. **qfq 的单日价格相等不代表无效。** 对比时应固定完整查询区间、过滤条件和锚点，并覆盖真实除权区间。不同结束日期的 qfq 价格没有共享锚点的保证。技术摘要已有复权计算和 provenance，不因原单日样例就推断 SMA/MACD 等全部使用未复权价。
2. **统一小数入口不等于直接改旧键。** 行情旧 pct_change 和 PIT 旧六项比率仍为百分数；新 ratio 入口供跨接口消费。行情收益的 `return_basis=source_reference`，技术摘要为 `adjusted_close_to_close`；除权日不强制两个不同定义完全相等。财务原指标已经是小数比例，不再除以 100；流动/速动比率为倍数，每股字段保持币种/股。
3. **未知换手率不能用当前流通股本推造历史值。** 本次选择诚实的 null，不承诺原稿估计的“约 0.20%”已被验证或补齐；其他来源的真实 0 也不能一律当缺失。
4. **财务裁剪与报告期遍历分别处理。** 一个报告期的大对象使用 summary/fields；多报告期使用现有 history。8 KiB 是本次默认摘要的消费目标，不是 MCP 协议通用硬上限；显式 service_layers 诊断和完整视图不在该承诺内。Cache-Control/条件请求未纳入本次实现。
5. **历史抓取时间不能补造。** `series.last_observation_date` 是全序列最新已存观察日；first_date/last_date 是请求日期过滤后区间边界；data_as_of 是真实成功抓取时间。历史时间未知仍 null，并标记 unknown_historical；latest 修订槽不是唯一历史修订号。
6. **合法正极端估值不默认裁到“理想均值”。** 新增显式阈值、raw 对照及剔除诊断；阈值参与 parameter_hash，统计算法版本为 relative_valuation.v2。异常主体的排名/溢价为空，非有限对外数值以 null 表达，避免序列化 500；有限原始负值仍可检查。
7. **PIT 可得日质量不臆造大小顺序。** 使用 exact/exact_event/statutory_deadline/delayed_estimate 白名单替代 min_available_at_quality。未知枚举返回 422，原 strict 可得日、effective_at、更正防护和 listed-only 边界保持。
8. **coverage 原复现含两个错误。** `?limit=3` 中 limit 未声明，修复后优先返回 422 unknown_query_parameter；只传合法字段但缺日期时，仍为 400 missing_date_range。daily 非法 adjust 为 422，technical/summary 既有手工校验仍为 400。

## 三、调用迁移示例

以下为发布后的只读验收示例；请将 BASE 指向已确认运行 1.2.0 合同的实例。它们不是本次已执行的线上验收记录。

```bash
BASE=http://localhost:8000/api/v1

# 固定区间比较复权，分页不改变该区间锚点。
curl "$BASE/quotes/daily?instrument_id=600519.SH&start_date=2020-01-02&end_date=2026-11-06&adjust=qfq&limit=2"
curl "$BASE/quotes/daily?instrument_id=600519.SH&start_date=2026-11-06&end_date=2026-11-06&adjust=hfq"

# 默认排除停牌；仅查停牌需同时显式包含停牌。
curl "$BASE/quotes/daily?instrument_id=000002.SZ&start_date=2016-06-01&end_date=2016-07-31&tradestatus=0&include_suspended=true"

# 默认摘要；旧完整载荷显式 full；fields 优先于 full 展开。
curl "$BASE/research/company/600519.SH/financial-statements"
curl "$BASE/research/company/600519.SH/financial-statements?view=full"
curl "$BASE/research/company/600519.SH/financial-statements?view=full&fields=revenue,net_income"
curl "$BASE/research/company/600519.SH/financial-statements/history?rolling_quarters=12&view=summary&fields=revenue,net_income"

# 最新利率；全历史改为显式升序，并按 next_offset 继续翻页。
curl "$BASE/research/risk-free-rate?series_id=china_treasury_10y&limit=2"
curl "$BASE/research/risk-free-rate?series_id=china_treasury_10y&order=asc&limit=2000&offset=0"

# 估值高值阈值为显式选择；PIT 质量筛选在最新可知期选择后执行。
curl "$BASE/research/company/600519.SH/valuation/relative?max_pe=100&max_pb=20"
curl "$BASE/research/financials/pit/cross-section?as_of=20260930&available_at_quality=exact,exact_event&exclude_unverified=true&exclude_discrepancy=true&limit=2"
```

客户端还需完成三项字段迁移：真实成交股数读取 `volume_raw`，复权股数读取 `volume_adj`；跨接口收益/比率计算使用相应 ratio 入口并检查 units/return_basis；展示最新价时先读取 EOD 日期、是否盘中数据和 staleness。`as_of` 是带市场时区的 bar 日期零点标签，`computed_at` 是响应装配时间，created_at/updated_at 是存储记录时间。日历/收盘截止依据不足时 staleness 为 null，不猜节假日或新鲜度。

## 四、原反馈待复核项和未纳入范围

- include_suspended/min_quality_score 的实现遗漏已通过可控停牌/质量 fixture 确认并修复；不能仅凭参数返回 200 证明其有效。新过滤会改变原先错误放行的行数，`tradestatus=0` 与默认 include_suspended=false 的交集应为空。
- 未证明生产库普遍存在“零量、OHLC 等前收、tradestatus=1”的错误状态。本次没有批量重标停牌或改写历史行。
- 期货、商品、外汇、行业模块未纳入本次全端点口径扫描；没有将未测模块宣称为已修复或已完整验收。
- requested_canonical_facts 保持分层事实选择/扩展语义，不是对外字段裁剪参数。include_local_core=false 本来就是已声明参数；其返回变化很小不能证明它是未知参数。include_snapshot 未声明，现明确返回 422。
- 实时源、HTTP 财务缓存、全库历史抓取时间回填、完整财务/利率 vintage、全市场数据修复及通用治理平台不在本次交付范围。
